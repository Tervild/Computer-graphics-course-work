# Ботанічний сад «Поділля»

Навчальний вебсайт, створений у межах курсової роботи з дисципліни «Комп’ютерна графіка»
(ВНТУ, група 3ПІ-24б, Домбровський В. В.).

- `index.html` – головна сторінка з анімацією «Цвітіння магнолії» та сюжетними ілюстраціями
- `flowers.html` – розділ «Квітник»
- `shrubs.html` – розділ «Чагарники»
- `trees.html` – розділ «Дендрарій»
- `calendar.html` – календар цвітіння за місяцями
- `visit.html` – маршрут прогулянки, правила саду, поради фотографам

Усі зображення намальовано у VectorCraft, анімацію зібрано у FilmCraft.
